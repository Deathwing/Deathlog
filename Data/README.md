# Deathlog Data

**Deathlog Data** is an optional standalone dependency package for [Deathlog](https://www.curseforge.com/wow/addons/deathlog).

It contains precomputed death statistics generated from over a million collected death records.

### What This Package Contains

* Precomputed per-creature, per-zone, and per-class death statistics
* Data for both Classic Era Hardcore and TBC Anniversary Soul of Iron servers

### Who Should Install This

* Install this package together with **Deathlog** only when using standalone packages.
* If you installed the bundled Deathlog release, this package is already included.

### What This Package Does Not Do

* No UI
* No slash commands
* No standalone player-facing functionality without Deathlog
