# Changelog

## 1.0.1

- When more than one copy is installed, the newest installed copy is used. Copies from before this release cannot be taken over and stay in use until they are updated.
- Loads on World of Warcraft: Forever with its own statistics and purge lists, built only from Forever clients. Each game version loads only its own data files. Until enough Forever deaths are collected the Forever files are empty, so Deathlog computes statistics from your own log there.
